# 倪海厦资料参考边界

## 可用方向

- 《天纪》：天、人、地三才；易经象数；紫微斗数；四柱命卦；阳宅与方位。
- 《天纪·四柱命卦》：天干地支取数、先天卦、后天卦、值年卦及六亲取象。
- 《人纪》：仅借鉴先辨证、重病机和经方思路；不根据命盘直接开方。

## 使用规则

1. 来源分为：原始/官方关联、文字整理、二次解读；后两类必须交叉核对。
2. 将倪氏方法作为辅助解释框架，不替代紫微安星、三方四正、四化和运限规则。
3. 将“象数、三才、方位”与八字、紫微分层表达，避免混成单一算法。
4. 涉及健康时，只讨论辨证方法和生活观察，不提供个人处方。
5. 对争议内容标注来源和置信度，不使用绝对化语言。
