# 河洛派方法、具体性与 Preflight 门禁 v1

本文件是 `doushu-v2` 的方法覆盖与输出质量补充。若历史参考文件仍写“三合派为主”或要求强行铺开三方四正，以本文件为准；交付、哈希和安全门禁仍遵守 `execution-contract-v2.md`。

## 一、方法主轴

只使用河洛理则作为主轴：一六共宗、气数位、原命盘宫干四化同步跟踪、一级管一级。禁止把中州六十星系、钦天来因宫或“先读命财官星曜画面”当作主轴。

- 三方四正只在“入三合方论格局”时作为次级参考。
- 流年、流月默认先看本宫与对宫；没有格局问题时，不强行铺三合。
- 天干始终取原命盘十二宫宫干；大限、流年、流月不重排宫干。
- 生年四化只用于原局和大限背景，不直接主断流年、流月。
- 大限用本命宫干看；流年用大限所在宫对应的原盘宫干看；流月用流年所在宫对应的原盘宫干看。
- 同一颗原盘禄或忌必须持续跟踪到大限、流年、流月；不能在前一层解释后丢弃。

默认通行四化表为：`甲廉破武阳 / 乙机梁紫阴 / 丙同机昌廉 / 丁阴同机巨 / 戊贪阴右机 / 己武贪梁曲 / 庚阳武阴同 / 辛巨阳曲昌 / 壬梁紫左武 / 癸破巨阴贪`。若用户指定河洛或师承口诀，报告开头必须声明并全程改用指定表。

气数位化禄、权、科入本宫、本宫三合或本宫对宫，读作本宫气数通；气数位化忌入本宫、冲本宫或入本宫交友，读作本宫气数伤。气数位之忌优先于本宫自坐忌，再优先于一般宫忌；同类宫互忌不作“双忌论死”，必须改写为内部消耗或结构调整。

大限、流年、流月遵守“一级管一级”：大限用本命宫位四化，流年用大限所在宫的原盘宫干四化，流月用流年所在宫的原盘宫干四化；生年四化不直接插手流年以下。

命财官互参固定按以下语义落地：命宫宫干化曜主财之得失和主动作为；官禄宫宫干化曜主运途、抉择和事业起伏；财帛宫宫干化曜主项目、竞争、人事差错和事业对错。命忌写资金缺口类型，官忌写运途或人为失误类型，财忌写项目或事业差错类型；气数位之忌落入哪条线，必须指出全盘最紧环节。

下承上才有力：大限四化进入本命三合或本对宫，才提高大限权重；流年四化进入大限三合或本对宫，才提高年度权重；流月四化进入流年本对宫或必要格局，才缩小到月份。任何一层没有上级承接，只能写观察窗口，不能写成确定应期。

化忌必须同时检查：坐忌、冲宫、冲宫之交友；禄与忌同宫、对宫或一九位相遇时，写“得而有失”或“双重损耗”；自化禄/权/科/忌分别写得而复失、争到底、看破或留麻烦。地支减重规则须前后一致：忌入寅卯通常减轻，巳午看有无制化，申酉、亥子及辰丑未戌按金生水、比旺、土制水判断；空亡则逢吉减吉、逢凶减凶。用户指定其他师承时，以用户规则覆盖并声明。

## 二、河洛坐标建档

每次实际分析必须先建立坐标记录：

```text
命宫 = 1，按命→父→福→田→官→友→迁→疾→财→子→夫→兄逆布至12；
命1、疾6 = 一六共宗；官9 = 命的气数位；
任意主问宫 X：从 X 当1逆数至9，明确写出 X 宫的气数位是 Y 宫；
命、财、官三宫分别列出原盘宫干及四化落点。
```

命、疾、福先看人的外在作为、身体/压力底盘和内在理念；再分别以命、财、官立太极，检查命干、财干、官干如何落入原盘十二宫。不能只写“命财官互参”，必须写清每颗化曜的落宫和对应主题。

资料不足时只询问会阻塞判断的项目：公历/农历出生年月日时、早晚子时、性别、出生地（需要真太阳时）、主问和时间范围。结论统一使用主题、气数、应期窗口和条件表达，不用铁口。

## 三、核心结论的具体性最低要求

每条核心结论必须同时写出以下字段；缺一项就标记为“不完整”，不得直接进入用户报告：

| 字段 | 最低要求 |
|---|---|
| 主宫与气数位 | 写宫名、地支、原盘宫干，并写“X宫的气数位是Y宫” |
| 河洛依据 | 写明本宫、气数位宫干、化曜落点；必要时补对宫或三合格局 |
| 主题判断 | 明确是财之得失、运途、人为抉择、关系、健康、迁移等哪一类 |
| 现实场景 | 至少写出对象/领域、具体变化和可能后果，例如上级、客户、合同、现金流、睡眠、居住或责任分配 |
| 触发条件 | 写出什么条件成立时会被放大，例如大限同宫、流年点燃、化忌冲同类宫或现实压力增加 |
| 时间范围 | 区分本命倾向、大限背景、流年触发和流月窗口；没有数据就写“未扩展” |
| 替代解释 | 至少给出一个不依赖单一断语的现实解释 |
| 验证点 | 给出最多两个可以核对的具体经历或现象 |
| 行动建议 | 给出可以执行的下一步，不写“注意”“把握机会”这类空泛动作 |
| 资料缺口 | 说明哪些依据重叠或缺失 |

### 具体场景写法

现实转换必须回答：谁或什么对象、在哪个领域、发生什么变化、通过什么机制、在什么条件下、可能付出什么成本或得到什么结果。

- 不合格：`事业有机会，但也有压力。`
- 合格：`若大限官干化禄进入本命官禄、而流年同宫点燃，较可能表现为岗位权限或项目资源增加；代价是绩效、交付责任和对上沟通同时增加。若没有对应的职责变化，则保留为项目曝光或客户合作增加的替代解释。`

以下词语不得单独充当结论：机会、贵人、波折、能量、适合管理、财运变好、关系有变化、注意健康。出现这些词时，后面必须立即补充对象、场景、触发条件和可观察表现。

## 四、河洛方法 Preflight

分析前逐项核对：

0. 已完成排盘后的飞星基础层：生年四化、命宫飞化、自化/互化、限年与流月数据。
1. 已完成 1—12 河洛编号、命疾一六、命的气数位和主问宫气数位。
2. 已列命干、财干、官干及生年四化落点；需要时列自化和最重跟踪忌。
3. 已声明四化表版本，以及是否使用用户指定的河洛口诀。
4. 已确认大限、流年、流月均不重排原盘宫干。
5. 已区分生年背景、大限定型、流年点燃、流月落地。
6. 已确认三方四正只是格局参考；流年以下不会无理由强行铺三合。
7. 每条核心判断都有具体场景、触发条件、时间范围、验证点和行动建议。
8. 健康、法律、投资等内容保持现实专业边界。

任何一项失败：状态置为 `blocked`，停止进入下一阶段；说明失败项和修复动作，修复后重新执行 Preflight。不得用免责声明、星曜罗列或“依据不足”替代已经可以完成的条件化判断。

## 五、交付 Preflight 与 Final

用户可见报告至少按以下结构组织：A. 河洛坐标；B. 原盘禄忌跟踪表；C. 命格与财官；D. 针对主问的具体断语；E. 限年应期；F. 方法声明。跟踪表至少列命干、财干、官干、生年忌和最重自化忌（如存在），并写明原盘落点、限年触发和现实含义。

实际命盘分析的固定展开顺序为：0. 盘面建档；1. 命、疾、福；2. 命财官气数总纲；3. 主问六亲或相关宫（本宫 + 气数位）；4. 用户要求健康时才展开健康专题；5. 大限；6. 流年；7. 用户要求准到月时才展开流月；8. 五段综合收口。未问领域不做十二宫平均流水账。

### 交付 Preflight（生成 HTML/PDF 前）

- 输入、命盘、运限、知识路由和实际读取资源已登记；
- `knowledge_route.warnings` 和 `blocking_issues` 为空；
- 分析稿已包含上述具体性字段；
- 独立复核同时有复核文件和语言审校文件；
- 用户正文至少覆盖 `input-context` 与 `action-plan`；健康模式追加 `medical-boundary`；
- `workflow_status = running`，模块 01—03 为 `passed`，质量交付和 delivery 仍为 `pending`；
- 此阶段不要求最终 HTML/PDF 已生成。

### Final 验收（生成并检查 HTML/PDF 后）

只有在 HTML/PDF 非空、渲染 QA 通过、文件 SHA-256 一致、所有阻塞项清零且 delivery = `passed` 后才可交付。Final 失败时必须报告失败阶段和修复动作，不得把草稿或未验收文件当成最终产物。

## 六、普通聊天输出的例外

如果用户只要求解释方法而不要求生成报告或文件，可以执行方法 Preflight 的逻辑核对，但不伪造 HTML/PDF、QA 文件或 Final 状态。只要进入实际命盘分析，仍必须完成坐标建档、气数位、四化跟踪和核心结论具体性检查。
