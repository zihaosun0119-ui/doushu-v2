# 健康透视图分析规则

## 使用边界

本规则只用于把紫微斗数、八字、五行和传统象义转译为生活观察框架，不用于疾病诊断、寿命判断、处方或替代正规医疗。任何持续、加重或影响日常功能的症状，都应优先接受正规医疗评估。

## 固定分析链

健康分析必须按以下顺序完成：疾厄宫 → 命宫 → 福德宫 → 父母宫 → 相关三方四正与对宫 → 主星和辅煞组合 → 宫位地支 → 八字寒暖燥湿、五行和十神 → 大限 → 流年 → 流月（只有资料支持时）→ 生活观察和风险管理。

## 紫微健康轴

- 疾厄宫：身体和生活习惯的主要观察入口。
- 命宫：行为模式、行动强度、风险暴露和体质表现。
- 福德宫：压力、睡眠、恢复、欲望和长期消耗。
- 父母宫：早年体质、家庭照护和先天背景的辅助观察。
- 迁移宫：外出、交通、环境变化和安全风险。
- 官禄宫：工作强度、职业压力、久坐、熬夜和劳动方式。

## 十二地支传统象义

子重点观察肾、膀胱、耳、骨髓和水液；丑重点观察脾胃、腹部和肌肉；寅重点观察肝胆、筋和四肢活动；卯重点观察肝胆、眼目、筋和节律；辰重点观察脾胃、腹部、皮肤和湿重；巳重点观察心、小肠、面部、咽喉和活动热；午重点观察心、小肠、血脉、舌和精神兴奋；未重点观察脾胃、腹部和肌肉承载；申重点观察肺、大肠、皮肤、筋骨和外伤；酉重点观察肺、大肠、鼻和皮肤；戌重点观察胃、脾、胸腹和长期积累；亥重点观察肾、膀胱、腰部、生殖和夜间水液。上述只是传统象义，不是现代医学器官定位。

## 八字健康交叉

先判断日主旺衰，再看寒暖燥湿、五行偏枯、十神压力、刑冲合害和大运流年。五行对应只用于提出观察问题：木对应肝胆、筋、眼目；火对应心、小肠、血脉和精神兴奋；土对应脾胃、肌肉和消化承载；金对应肺、大肠、皮肤和呼吸；水对应肾、膀胱、耳、骨和水液。不能因为五行偏弱或偏旺就断定对应器官患病。

## 具体事件和年度输出

每个健康判断必须写明依据、触发机制、现实表现、时间范围、有利条件、不利条件、风险等级和验证问题。年度分析必须区分本命长期倾向、大限十年背景、流年触发和现实条件，不得把化忌或煞星直接写成疾病。流年重点只能写成“需要观察的生活主题”，例如睡眠压缩、工作过劳、饮食紊乱、外出安全、久坐和压力恢复。

## 风险等级

- 低：只有单一象义或没有时间触发，只能提出观察方向。
- 中：本命、大限、流年或八字出现两层以上相互支持的生活方式信号。
- 高：多宫位、多层运限和现实反馈重复指向同一安全或健康管理主题；即使如此，也不能写成疾病诊断。

## 输出要求

最终健康章节必须包含：健康总轴、紫微健康轴、十二地支身体象义、五脏六腑和身体部位的传统观察、八字寒暖燥湿、主星与煞星组合、风险分级、2026—2030流年观察、可执行的生活管理计划、前事验证问题和医疗边界说明。

## v2 用户呈现补充规则

完整分析可以保留全部传统象义，但用户正文必须筛选一至两个主要脏腑观察方向，并具体写出对应的状态表现。例如脾胃方向应连接饮食节律、食欲、腹胀、消化和疲劳；肝胆方向应连接压力、情绪紧绷、眼目、筋和肩颈；心与心神方向应连接睡眠、精神兴奋、心慌感受和压力恢复；肺与皮肤方向应连接呼吸、鼻咽、皮肤和环境；肾与水液方向应连接腰腹、夜间、尿液变化和恢复；筋骨和眼目方向应连接久坐、用眼、拉伤和活动限制。

上述只是传统观察方向，不是器官疾病定位。用户正文不得只写“注意五脏六腑”，也不得把“潜在风险”写成隐藏疾病。验证内容改写为自然段，最多保留两个高区分度确认点。
