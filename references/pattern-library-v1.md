# 格局与结构组合库 v1

本库包含 120 条分析组合。`传统`指有古籍/流派名称的候选格局；`结构`指为分析而建立的组合卡，不冒充传统格局。每条必须结合实际星曜、宫位、四化、庙旺和运限使用，不能直接等同事件。

字段：编号｜类型｜组合｜主要观察｜反证或限制。

|A05|结构|身宫入财帛|价值交换和资源管理突出|不能直接断财富高低|
|A06|结构|身宫入迁移|外部环境推动成长|稳定环境也可表现为跨圈层|
|A07|结构|身宫入福德|内在状态影响执行和选择|不能等同心理疾病|
|A08|结构|命宫强、身宫受制|能力可见但现实展开受环境限制|需检查大限和资源条件|
|A09|结构|命宫受制、身宫有助|早期自信不足，行动后改善|需现实反馈确认|
|A10|结构|命迁轴强|外部机会、移动和身份变化突出|不等同必然异地发展|
|A11|结构|命福轴紧张|高标准、思虑和恢复问题|无持续压力时权重下降|
|A12|结构|命官财三方成链|能力—工作—收入相互转化|权责或市场条件可能破链|

## 使用门禁

1. 传统格局必须注明来源和完整成立条件；J 组当前均为候选。
2. 结构组合用于建立问题，不得包装成古籍格局。
3. 每次报告最多选 3—6 条最相关组合，不遍历输出 120 条。
4. 每条进入结论前，必须有至少两类额外依据或用户现实反馈。
5. 格局库只增加分析差异，不增加确定性预测。
