# Doushu v2 事业专项深入分析

## 目标

建立“职业人格 → 驱动力 → 能力 → 工作机制 → 角色 → 环境 → 价值变现 → 风险 → 成长路径 → 时间 → 行动”的推理链。不得从单星或单一官禄宫直接指定职业。

## 1. 证据与反证

基础证据优先使用命宫、身宫、福德宫、官禄宫、财帛宫、迁移宫、交友宫及其气数位、本宫/对宫、四化、大限和流年；只有论格局时才补充相关三合方。重要结论至少使用两个独立证据源；同一宫内多颗星只算一个来源。

每个重要结论都要同时写出：支持结构、限制或反向结构、成立条件、现实表现、验证点、资料缺口。出现“喜欢变化但需要稳定”“能力强但变现不稳定”等矛盾时，输出条件化综合结论，不选择性忽略反证。

## 2. 职业模型

按以下顺序分析：

### 职业人格与驱动力

判断命主主要由收入、稳定、成就、自主、创造、影响力、专业认可、成长、竞争或解决问题中的哪些因素驱动，并说明长期得不到满足时可能出现的倦怠方式。

### 最佳工作机制

比较：独立与团队、自主与规则、稳定与变化、深度与多任务、创造与执行、前台与后台、专业与管理、独立产出与高人际密度、快反馈与长周期项目。最后用一句现实条件总结，例如“稳定平台＋清晰目标＋较高自主权＋工作内容持续变化”。

### 能力结构

从分析、学习、表达、沟通、执行、决策、风险判断、资源整合、研究、应变和组织协调中筛选实际有依据的优势。区分核心优势、辅助能力、尚待验证能力和容易被高估的能力，不为每项能力强行下结论。

### 角色、组织与行业场景

先判断角色，再判断组织，最后判断行业。只从专家、分析、策略、项目、产品、运营、顾问、管理、资源整合、创意和创业中筛选与用户问题及盘面相关的角色，默认不列职业清单；需要比较时最多列四类，并合并相近路径。每类说明匹配能力、工作机制、适合场景、潜在代价或验证方法中相关的部分。

组织环境分为最匹配、可适应、长期高消耗三类；行业只作为工作机制的应用场景，不使用“某星等于某行业”的推断。

### 财富与价值变现

区分官禄宫的价值创造方式和财帛宫的收入转换方式，判断固定工资、奖金、提成、项目收入、专业服务、股权、多收入来源等哪类更匹配。必须说明能力与收入不等价时的缺口，例如销售、绩效、回款、定价或股权条件。

## 3. 优势链与风险链

至少输出两条优势链：

```text
盘面结构 → 能力形成 → 工作行为 → 环境反馈 → 长期优势
```

至少输出两条风险链：

```text
优势或需求 → 过度使用条件 → 风险机制 → 现实表现 → 长期代价 → 预警信号 → 修正动作
```

优先覆盖：责任与权限、信息和沟通、团队客户、合同合规、跳槽变动、收入现金流、压力恢复。不得只写“事业有波折”或“容易三分钟热度”。

## 4. 团队与创业

结合交友、官禄和命宫判断命主更适合靠个人专业能力，还是通过组织他人放大价值。只有用户询问创业，或盘面与任务明显涉及创业时，才分析创业动机、能力、合伙方式和风险；不得因为存在自主或变化倾向就直接建议创业。

## 5. 职业路径与时间

建立三阶段路径：能力积累、角色升级、价值放大。价值放大方式从专业深度、管理、商业、资源、创业、个人品牌或资本中择其有依据者。

时间按“本命 → 大限 → 流年”判断，使用 Level 0—3：

- Level 0：事业主题平稳；
- Level 1：责任、压力或关注度变化；
- Level 2：岗位、项目、收入或组织变化增加；
- Level 3：多个独立结构共同支持明显转折。

Level 3 才能称为值得重点关注的职业窗口；不得用单一流年直接断跳槽、晋升、创业或发财。

## 6. 分析层交付格式

分析层只需输出：一句核心职业判断、证据与反证、职业模型、两条优势链、两条风险链、时间窗口、验证点、两至四条行动建议和资料缺口。完整依据集中保留在专业附录；用户正文由 `user-rendering-v3.md` 改写。

## 禁止

- 单官禄宫定职业；
- 单星对应行业；
- 财帛好等于富有；
- 吉星等于成功、煞星等于失败；
- 单一流年断跳槽、创业或晋升；
- 虚构职位、收入和经历；
- 使用“必成、一定发财”等绝对表述；
- 数据不足时强行具体预测。
