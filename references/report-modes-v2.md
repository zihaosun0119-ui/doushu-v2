# Doushu v2 专项报告层

专项报告层不重新推演命盘，只从条件化深入分析层接收已经完成的对应方向结论，并转换为领域语言。

专项报告层不负责决定分析方向。分析方向必须在输入阶段确定，并在深入分析阶段执行。

所有专项报告共用：

1. 资料说明：实际使用的输入、时间范围、关系状态和资料限制；
2. 一句话主题结论；
3. 现实可能性分流；
4. 一段自然的用户确认引导；
5. 具体行动建议；
6. “现在怎么做”：一个优先问题、现实核对点、一个低成本动作、观察期限、推进条件和调整/止损标准；
7. 专业依据附录。

需要选择或决策时，再读取 `decision-support-v2.md`，不要把决策内容混入命理推论段。

不要把验证问题拆成一串问卷。将需要用户确认的现象、时间和影响写进一段完整文字，最多提出两个真正能区分路径的问题。

## 健康专项

重点抽取疾厄宫、命宫、福德宫、父母宫、迁移宫、官禄宫、气数位、本宫/对宫、辅煞、四化、八字和运限；只有论格局时补充三合方。

根据盘面和用户问题选择一至三个主要观察方向，优先讨论与当前现实最相关的睡眠恢复、压力、饮食消化、久坐筋骨、呼吸皮肤、腰腹水液或外出安全等状态，不强制覆盖固定数量。

健康报告必须点出具体的脏腑观察方向，不能只写“注意身体”或“注意五脏六腑”。根据实际盘面选择一至两个主要系统，例如脾胃、肝胆、心与心神、肺与皮肤、肾与水液、筋骨和眼目，并说明：盘面为什么指向它、可能通过哪些具体状态表现、什么生活条件会放大、哪些现实因素也可能造成同样表现。

表达示例：如果盘面同时支持脾胃与肝胆方向，应写成“压力和作息变化时，可能先表现为食欲、腹胀、消化节律变化，同时伴随情绪紧绷、眼疲劳或肩颈不适”，而不是只罗列“脾胃、肝胆有风险”。

允许提出“尚未显性化的健康管理风险”，例如长期熬夜、压力累积、饮食失序、久坐或恢复不足，但不得写成隐藏疾病、必然患病或命盘确诊。每个方向说明可能表现、触发条件、替代解释、自然验证引导、生活管理和医疗边界。

## 事业专项

深入规则使用 `career-analysis-v2.md`；专项层重点抽取命宫、官禄宫、财帛宫、迁移宫、福德宫、交友宫、身宫和运限。

围绕工作机制、能力瓶颈、价值变现、组织关系和时间行动中与当前问题相关的部分形成现实画像。稳定平台、换工作、项目制、专业输出、合作、创业或异地机会只在盘面和用户问题支持时展开，相近路径合并表达；默认不列职业清单。

## 感情专项

深入规则使用 `relationship-analysis-v2.md`；专项层重点抽取夫妻宫、身宫、命宫、福德宫、迁移宫、交友宫、财帛宫、田宅宫和运限。

夫妻宫同时按感情、客户、合伙、长期项目、契约和共同生活理解。根据用户状态分流：有稳定关系、无稳定关系、暧昧、异地、关系影响工作、关系影响居住，以及合作关系代替婚恋主题。

固定输出“关系底层模式 → 长期适配对象 → 对象现实画像与相识场景 → 当前关系判断 → 对方投入与发展 → 冲突与长期运行 → 分开/复合或未来风险 → 关系时间地图 → 行动建议”。根据状态调整重点：单身看准备度、机会和筛选；暧昧看吸引与适配、投入和关系定义；稳定关系看承诺、修复和现实融合；分手/冷战/复合看问题是否改变、持续行动、观察期和止损线。

重点分析关系需求、互动方式、冲突来源、承诺条件、时间金钱边界和现实行动。对象事业只写工作属性、环境、节奏、专业程度和责任方式，不断定具体职业；相识场景按高/中/低关联输出。对方态度优先依据现实行为，所有时间窗口保留条件表达。不得把流年写成必然恋爱、结婚、分手或遇到某人。

## 社交专项

重点抽取交友宫、兄弟宫、迁移宫、命宫、福德宫、官禄宫、夫妻宫和运限。

区分朋友、同事、客户、团队、师长、公共社交和长期合作，不把所有人际关系合并成“人缘好或不好”。

重点输出：社交入口、容易形成的关系类型、资源与支持、边界问题、责任不对等、沟通冲突、当前阶段和可执行的社交筛选方法。

## 完整命局报告

完整报告由 `report_mode = complete` 触发，并调用 `modules/03-complete-report.md`。它可以包含所有领域，但仍遵守结论登记和去重规则：飞星与河洛分别成链，关键三方四正按需核验，命宫、身宫、核心结构集中分析一次；专项领域只写该结构在现实中的表现。没有用户明确的流年或流月范围时，不自动补造具体月份。
