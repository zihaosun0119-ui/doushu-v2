# 十二宫分析矩阵 v1

每个宫位必须从以下 12 个维度交叉解释，不得只写宫位的单一关键词：

1. 本义；2. 现实领域；3. 行为模式；4. 资源能力；5. 压力风险；6. 人际关系；7. 工作角色；8. 财务物质；9. 身体生活方式；10. 家庭环境；11. 大限变化；12. 流年触发与验证。

## 十二宫入口

| 宫位 | 核心观察入口 | 优先联动 |
|---|---|---|
| 命宫 | 自我定位、行动方式、选择标准 | 身宫、官禄、财帛、迁移 |
| 兄弟 | 同辈、手足、信息与竞争 | 命宫、仆役、夫妻 |
| 夫妻 | 亲密关系、契约、长期绑定 | 福德、官禄、财帛、迁移 |
| 子女 | 创造、项目、后辈、输出 | 夫妻、田宅、官禄 |
| 财帛 | 收入、资源、价值交换 | 官禄、福德、夫妻 |
| 疾厄 | 身体状态、习惯、恢复 | 命宫、福德、迁移、官禄 |
| 迁移 | 外部环境、移动、机会与风险 | 命宫、官禄、仆役 |
| 仆役 | 团队、客户、朋友、合作 | 官禄、迁移、兄弟 |
| 官禄 | 工作内容、权责、社会角色 | 命宫、财帛、迁移、福德 |
| 田宅 | 居住、家庭资产、稳定感 | 父母、福德、子女 |
| 福德 | 压力、睡眠、欲望、恢复 | 命宫、夫妻、疾厄、官禄 |
| 父母 | 早年背景、支持、权威与制度 | 命宫、田宅、疾厄 |

## 使用规则

每次专项分析只加载相关宫位，但必须先确认主问宫、气数位和对宫；三方四正只在需要入三合方论格局时检查。若只使用本宫而没有气数位或对宫，不得声称完成完整宫位分析。每个判断至少写出：依据、现实对象或变化、成立条件、时间范围、替代解释、验证方式和行动建议。

## 十二宫十二维展开

### 命宫

1本义：自我与人生主轴；2现实：身份和选择；3行为：决策速度与风格；4资源：核心能力；5风险：自我要求或方向摇摆；6人际：给人的第一印象；7工作：承担责任的方式；8财务：价值感与消费判断；9身体：行动强度和风险暴露；10家庭：与原生期待的关系；11大限：身份重建；12流年：当年自我议题及前事核对。

### 兄弟宫

1本义：手足与同辈；2现实：同学、同行、近距离合作；3行为：比较、协商与竞争；4资源：同辈信息和互助；5风险：口舌、资源分配；6人际：熟人边界；7工作：同级协作；8财务：共同支出和借贷；9身体：仅作压力环境辅助；10家庭：手足责任；11大限：同辈关系重组；12流年：合作、争议或消息触发。

### 夫妻宫

1本义：伴侣与契约；2现实：亲密关系、长期合作；3行为：靠近、承诺和冲突方式；4资源：关系提供的支持；5风险：权责、距离和期待落差；6人际：择偶与绑定标准；7工作：客户、合伙和合同；8财务：共同资金和分工；9身体：关系压力对状态的影响；10家庭：共同生活；11大限：关系/合作成为主轴；12流年：确认、调整或边界谈判。

### 子女宫

1本义：子女与产出；2现实：作品、项目、后辈；3行为：创造与照顾方式；4资源：表达和生产能力；5风险：控制、投入过度；6人际：与后辈互动；7工作：项目孵化和交付；8财务：养育或项目成本；9身体：生育问题只在医疗资料支持时讨论；10家庭：养育安排；11大限：输出与责任扩大；12流年：项目、作品或后辈事件。

### 财帛宫

1本义：收入与资源；2现实：现金流、定价、资产；3行为：赚钱和花钱方式；4资源：变现能力；5风险：债务、波动、错误承担；6人际：利益交换；7工作：收入机制；8财务：储蓄、投资和支出结构；9身体：财务压力的生活影响；10家庭：共同资产；11大限：价值与资源重配；12流年：收入、支出和合同窗口。

### 疾厄宫

1本义：身体与习惯；2现实：睡眠、饮食、活动和恢复；3行为：压力下的身体反应；4资源：恢复和照护能力；5风险：过劳、外伤和节律失序；6人际：照护与求助；7工作：职业暴露；8财务：医疗和健康管理成本；9身体：脏腑象义只作观察；10家庭：早年照护；11大限：健康管理优先级上升；12流年：症状和生活条件核对，不能诊断。

### 迁移宫

1本义：外部环境；2现实：出行、异地、跨圈层；3行为：面对变化的方式；4资源：平台和外部机会；5风险：交通、安全和适应成本；6人际：陌生人和公共关系；7工作：外派、市场和跨域；8财务：迁移成本与外部收入；9身体：环境对状态的影响；10家庭：离家与居住调整；11大限：外部变化主轴；12流年：移动、转换和机会窗口。

### 仆役宫

1本义：朋友、团队和下属；2现实：客户、同事、社群；3行为：合作和授权方式；4资源：人脉与信息；5风险：责任转嫁和承诺落空；6人际：关系分层；7工作：团队执行与客户质量；8财务：分账、佣金和合作成本；9身体：社交消耗；10家庭：朋友与家庭边界；11大限：网络重组；12流年：团队、客户和合作筛选。

### 官禄宫

1本义：事业与社会角色；2现实：岗位、职责、绩效；3行为：执行和管理方式；4资源：专业能力和权限；5风险：权责不等、过劳；6人际：上下级与组织关系；7工作：内容、环境和成长机制；8财务：薪资和回报兑现；9身体：久坐、熬夜和劳动负担；10家庭：工作对生活的影响；11大限：职业重建；12流年：岗位、项目和考核变化。

### 田宅宫

1本义：居所与家产；2现实：住房、家庭资产、空间；3行为：建立安全感的方式；4资源：稳定基础；5风险：资产负担和家庭摩擦；6人际：同住关系；7工作：家庭办公或不动产关联；8财务：房租、房贷和大额支出；9身体：居住环境影响；10家庭：家庭结构核心；11大限：居住和资产调整；12流年：搬家、装修或家庭安排。

### 福德宫

1本义：精神与享受；2现实：睡眠、欲望、恢复；3行为：独处和减压方式；4资源：心理弹性与满足感；5风险：思虑、空虚、过度刺激；6人际：亲密距离和个人空间；7工作：意义感与职业消耗；8财务：消费补偿；9身体：心神、睡眠与恢复观察；10家庭：内在安全感；11大限：价值观和生活方式重建；12流年：压力、休息和方向评估。

### 父母宫

1本义：父母与长辈；2现实：制度、师长、文件和支持；3行为：面对权威的方式；4资源：家庭和制度帮助；5风险：期待、控制和责任；6人际：与长辈及导师互动；7工作：上级、资质和制度；8财务：家庭支持或负担；9身体：早年体质背景辅助；10家庭：原生家庭关系；11大限：权威和支持系统变化；12流年：父母、证件、制度或照护事件。
