# Doushu v2 通用分析层

## 目标

通用分析层先回答所有方向都需要的基础问题；随后根据输入阶段生成的“分析方向”，条件化深入健康、事业、感情、社交等领域。

它不直接写最终用户报告，也不默认完成所有领域。

## 方向选择规则

```text
用户明确一个方向：只深入该方向。
用户明确多个方向：按指定顺序深入多个方向。
用户要求完整命局：按完整报告范围深入全部必要方向。
用户未说明方向：先询问主要关注领域，不直接生成全领域长报告。
```

每个方向都先使用最小基础盘面，再加载该方向需要的宫位、星曜、四化、八字和运限资料。

## 固定证据链

资料核验 → 河洛1—12坐标 → 命疾福 → 命财官气数位 → 主问宫与气数位 → 本宫与对宫 → 必要的三合格局参考 → 原盘宫干四化 → 大限 → 流年 → 流月（数据完整时）→ 前事验证。

## 核心判断合同

每个重要判断登记一次：

```text
结论编号：唯一编号
核心判断：一句话
盘面依据：实际使用的宫位、星曜、四化、运限或八字
现实主题：工作、收入、关系、健康、家庭或迁移
可能路径：有依据的现实分支
替代解释：同一结构的其他表现
成立条件：什么情况下更明显
时间窗口：本命、大限、流年或流月
验证点：用户可以确认的经历或现象
资料限制与缺口
完整解释位置：只指定一个章节
```

核心结论必须同时写出主宫、气数位、原盘宫干、化曜落点、具体现实对象、触发条件、时间窗口、替代解释、验证点和行动建议。缺少现实对象或触发条件时，只能标记为“不完整”，不能把抽象词直接写成结论。

同一结论在其他章节只能引用编号，并说明它在该领域的具体表现，不得再次完整解释全部依据。

## 可能性规则

保留所有有现实意义且有盘面支持的路径，分为：

- 主要路径：多类依据共同支持；
- 次要路径：两类以上依据支持，但需要现实条件；
- 替代路径：主路径没有发生时，可能转移到其他领域；
- 补充观察：单一或弱依据，只作提醒。

不得把本命倾向直接写成某年必然事件。

## 时间规则

每个时间判断都区分：

1. 本命基础；
2. 大限背景；
3. 流年触发；
4. 现实条件；
5. 可能表现；
6. 反向表现；
7. 时间范围和资料缺口。

流年数据不存在时标注“未扩展流年”，不得补写具体年份或月份。

## 现实翻译规则

先保留专业判断，再翻译为用户可观察的对象：工作职责、收入、合同、时间、关系、居住、睡眠、饮食、压力和安全。

不能只写“贵人、机会、波折、能量、适合管理、财运变好、关系有变化”等抽象词，必须说明它通过什么人或对象、什么场景、什么责任/资源变化、什么触发条件和什么现实成本表现。
