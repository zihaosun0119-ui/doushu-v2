# Doushu v2 决策支持层

专项报告不只描述命盘，还要帮助用户整理选择和现实验证。决策支持层不替用户决定，也不重新推演命盘。

## 通用结构

每个重要主题都转换为一段连续判断，包含：

1. 盘面主题；
2. 现实中可能出现的两到三条路径；
3. 区分这些路径的现实信号；
4. 每条路径需要成立的条件；
5. 用户需要核实的关键事实；
6. 一个低成本验证动作；
7. 继续、暂停或调整的条件。

不要把这些内容全部拆成问题清单。优先使用完整段落，必要时使用一个简短对比表。

## 事业决策支持

职业报告应从六个现实维度比较选择：工作任务、工作环境、能力使用、权限与责任、收入与现金流、成长和退出成本。

当用户存在多个选择时，输出：

- 选项A更适合的条件；
- 选项B更适合的条件；
- 两个选项共同的风险；
- 需要通过现实信息核实的差异；
- 未来30天可以完成的验证动作。

验证动作优先使用：试做小项目、访谈从业者、核对岗位权限、确认奖金和付款规则、比较现金流和恢复成本。命盘只提供条件化辅助，不代替现实调查。

## 感情决策支持

感情报告应从关系基础、沟通与冲突、修复能力、信任、承诺、共同生活和共同目标观察关系。

需要区分：

- 当前矛盾是一次性可解决问题，还是长期反复问题；
- 双方是否能在冲突后恢复沟通；
- 承诺是否落实为时间、金钱、城市和行动；
- 关系是在增加安全感，还是持续消耗个人边界。

报告不直接给出“继续/分手”结论，而是说明继续推进、暂缓绑定、重新沟通或退出关系分别需要什么条件，以及用户可以先观察什么行为。

## 健康决策支持

健康报告可以指出尚未显性化的健康管理风险，但不能称为隐藏疾病。

每个具体脏腑方向必须写成：

```text
脏腑观察方向
→ 盘面依据
→ 可能的状态表现
→ 现实触发条件
→ 可能造成的生活影响
→ 替代解释
→ 低成本记录或检查
→ 何时需要正规医疗评估
```

例如脾胃方向要连接饮食节律、食欲、腹胀、消化和疲劳；肝胆方向要连接压力、情绪紧绷、眼目、筋和肩颈；心与心神方向要连接睡眠、精神兴奋和压力恢复。不能只罗列脏腑名称，也不能从命盘直接推出疾病。

## 报告收束

结尾只保留：

1. 最值得优先处理的一件事；
2. 一项现实核对；
3. 一个低成本下一步；
4. 需要暂停或寻求专业帮助的条件。
