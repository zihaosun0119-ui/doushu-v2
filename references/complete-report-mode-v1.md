# 完整命局报告模式 v1

## 一、触发方式

用户出现以下表达时，将任务设为 `report_mode = complete`、`reportTypes = ["full"]`：

- 完整命局
- 全盘分析
- 完整分析报告
- 全盘详细分析
- 全面分析我的命盘
- 详细分析一生、事业、财务、感情和健康

如果用户同时指定事业、感情、流年或流月，保留这些范围作为完整报告中的重点；不得因为进入完整模式而擅自扩大出生资料或时间范围。

## 二、模式目标

完整模式不是把所有知识库全文堆进报告，而是自动完成一次可追溯的全盘分析：

1. 飞星与河洛分别运行两条独立推理链；
2. 飞星链不能只保留为附注，必须独立输出生年、命飞、限年、流年和必要流月因果；
3. 河洛链必须输出命宫起1逆布12宫、命疾一六、命财官气数位、主问宫气数位和原盘宫干四化；
4. 三方四正只作为结构核验，但对命、财、官、迁、夫妻、福德、交友等关键宫位必须在实际有承接时展开；
5. 结论必须翻译为现实对象、变化、触发条件、时间窗口、验证点、替代解释和行动；
6. 领域之间只保留有传导依据的联动，不做十二宫平均流水账。

## 三、默认任务配置

```text
report_mode: complete
report_types: [full]
method_mode: dual-separated
primary_profile: helu（用户另指定飞星时改为 feixing）
baseline: feixing-required
trine_review: required-for-relevant-palaces
time_scope: 本命 + 当前大限；用户给出年份或月份时追加相应层级
daily_hourly: off，除非用户明确要求
case_validation: off，除非用户提供前事或要求校盘
```

“双链”不是把两套口诀混为一个结论：每条结论先登记飞星链或河洛链的来源，再在对照栏写一致、部分一致、冲突及取舍。

## 四、固定分析顺序

### 1. 资料与数据

核对历法、日期、时辰、早晚子时、性别、出生地、时区、真太阳时风险、四化表和时间范围。输出缺失资料、默认值和不确定性。

### 2. 盘面建档

登记五行局、命宫、身宫、十二宫地支、原盘宫干、十四主星、主要辅煞、亮度、生年四化、自化字段状态、大限和指定流年数据。

### 3. 飞星独立链

按“电源 → 命宫飞化/自化 → 大限体用 → 流年开关 → 流月落地”推演。登记生年四化、命宫飞化、自化、互化/连环忌、禄忌同宫或对冲、气数位触发和每层的源宫/落宫。

飞星模式若被用户明确指定为主轴，才启用大限活盘和动态大限宫干飞化；完整模式默认仍保留飞星链，但不得把动态重排宫干写成河洛结论。

### 4. 河洛独立链

从命宫起逆布1—12；标出命1、疾6、官9、命的气数位、财的气数位、官的气数位和主问宫的气数位。按原盘宫干完成命、财、官四化及禄忌同步跟踪，明确大限、流年、流月的一级管一级关系。

### 5. 关键结构核验

至少核对：

- 命—疾一六共宗；
- 命—财—官及迁移的职业、资源、外部环境链；
- 夫妻—官禄的合作/契约与事业对待；
- 财—福的收入与使用、动与静；
- 交友—官禄的团队、客户、信息和责任传导；
- 用户明确提问的其他宫位。

三方四正输出“本宫 → 三方 → 对宫 → 四化/星曜承接 → 现实表现”，不只罗列宫名；没有上级承接时只写结构参考，不再展开具体结论。

### 6. 全盘现实专题

按结构而非十二宫流水账组织：

- 命、疾、福：外在行动、压力底盘、内在理念；
- 事业、财务、迁移：职业机制、收入方式、平台与环境；
- 夫妻、交友、兄弟：关系、合作、团队和边界；
- 父母、田宅、子女：家庭、文书、居住、作品和传承；
- 健康：只写压力、作息、恢复、观察和就医边界，不作诊断。

每个专题只保留与当前盘面有依据的2—4条主结论，避免重复解释同一条禄忌链。

### 7. 运限与决策

用户给出大限、流年或流月范围时，按层级追加；无指定年份时不自动伪造未来月份。存在跳槽/创业、留下/离开等选择时，调用决策支持，输出路径条件、现实核对事实、低成本验证动作、推进条件和暂停/调整信号。

## 五、完整报告输出结构

```text
A. 资料、口径与数据完整度
B. 全盘坐标与十二宫建档
C. 飞星独立因果链
D. 河洛坐标、命疾福和命财官气数
E. 关键三方四正核验
F. 全盘现实专题
G. 大限、指定流年和指定流月
H. 多派对照与冲突说明
I. 现实路径、验证点和行动方案
J. 资料缺口、资料缺口和方法声明
```

用户只输入“生成完整分析报告”时，默认输出本命与当前大限；如果上下文已有“今年、某年、近几个月”等范围，则沿用并追加对应时间层，不重复询问。

## 六、禁止事项

- 不把飞星链压缩成几句四化落点；
- 不把三方四正当作河洛气数位的替代语法；
- 不把中州、钦天、许铨仁规则混入河洛原盘宫干；
- 不因“完整”而擅自输出流日、流时或未请求的确定事件；
- 缺少自化、流月或前事资料时，明确标记缺口；
- 不把星曜组合、格局名称或单一化忌写成必然结果。

## 七、模式门禁

完整模式除通用飞星基础检查和所选主轴检查外，还必须记录：

- `complete_scope`：本命、领域和时间范围覆盖；
- `feixing_full_chain`：飞星独立链已完成；
- `helu_full_chain`：河洛独立链已完成；
- `trine_review`：关键三方四正已按需核验；
- `decision_support`：有多个选择时已完成路径对照；无选择时记录 `not_applicable`；
- `cross_domain`：事业、财富、关系、迁移等联动已登记或记录不适用；
- `concrete_conclusions`：核心结论满足具体性要求。

上述项目未完成时，完整报告只能停留在分析草稿，不能标记为最终交付。
