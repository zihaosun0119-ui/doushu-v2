# 流月分析输出规范 v1

## 一、基本原则

流月分析分为两层：

```text
内部层：完整合并本命、大限、流年、流月、宫位、星曜、四化、叠宫和现实条件
用户层：只呈现最重要的主题、表现、行动和观察信号
```

内部证据用于提高结论质量，不默认全部展示给用户。

内部推演顺序固定为：

```text
流月数据确认 → 流年背景 → 大限背景 → 流月本宫与对宫 → 原盘禄忌跟踪 → 必要的三合格局参考 → 证据合并 → 用户现实翻译
```

其中流月本宫与对宫负责判断本月直接事件，原盘禄忌跟踪负责确认触发来源与层级；三方四正只有在需要入三合方论格局时才加入，不能替代本宫、对宫和气数位。

## 二、用户可见内容

每个月默认只输出以下五部分：

### 1. 本月核心主题

用一句话回答：这个月最值得关注的变化是什么？

不要写抽象的“能量增强”“运势较好”，要写成现实主题，例如责任增加、合作推进、关系重新协商或现金流需要管理。

### 2. 重点领域

只保留最活跃的 2–3 个领域。领域包括事业、财富、感情、人际、迁移、健康和家庭。

每个领域用一句话说明可能变化，不展开十二宫列表。

### 3. 现实表现

列出 2–4 个用户可以观察的场景，例如新任务、合作邀约、回款节点、沟通减少、异地安排或责任边界变化。

### 4. 本月行动

给出 2–4 条具体动作，优先使用确认、推进、试行、延后、复盘、设置边界等动词。

### 5. 观察信号与不确定性

列出 1–3 个验证信号，并用一句话说明：流月代表议题活跃度，不代表事件必然发生。

## 三、默认不展示的内容

以下内容保留在内部分析记录，除非用户追问依据：

- 十二宫逐宫展开；
- 全部星曜清单；
- 无关的完整三方四正铺陈或全部宫位计算过程；
- 所有叠宫数组；
- 内部活跃度评分；
- 重复的本命、大限和流年解释；
- 与用户问题无关的领域联动。

## 四、重点筛选规则

用户层最多保留 3 个重点领域。优先级为：

1. 流月命宫直接指向的领域；
2. 月干四化明显触发的领域；
3. 本命、大限、流年、流月叠宫集中的领域；
4. 用户明确提出的问题领域；
5. 对现实决策影响最大的领域。

如果多个领域活跃度接近，优先保留与用户当前问题关系最强的领域。

## 五、用户层模板

```text
本月核心主题：{一句话结论}

重点领域：
- {领域一}：{现实变化}
- {领域二}：{现实变化}
- {领域三，可选}：{现实变化}

可能表现：
- {场景一}
- {场景二}
- {场景三，可选}

本月建议：
- {动作一}
- {动作二}
- {动作三，可选}

观察信号：{用户可以核对的现实现象}
不确定性：流月反映议题活跃度，不代表事件必然发生，仍需结合现实条件和个人选择。
```

## 六、追问时再展开

用户询问“为什么”时，按以下顺序补充依据：

```text
流月触发 → 流年背景 → 大限背景 → 本宫与对宫 → 气数位和原盘禄忌链 → 必要的三合格局 → 现实解释
```

每次只解释与当前问题相关的依据，不自动贴出整张盘。
