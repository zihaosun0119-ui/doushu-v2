# 主星联动规则 v1

## 分析顺序

```text
主星功能 → 同宫组合 → 庙旺平陷 → 三方四正 → 对宫 → 四化 → 大限 → 流年 → 现实表现
```

## 十四主星最低覆盖项

紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军，每颗主星必须分别记录：

- 基本功能；
- 有利表现；
- 失衡表现；
- 不同宫位变化；
- 同宫主星联动；
- 三方四正和对宫修正；
- 四化和运限触发；
- 不能直接推出的结论。

## 辅星和煞曜联动最低覆盖项

左辅、右弼、文昌、文曲、天魁、天钺、禄存、天马、擎羊、陀罗、火星、铃星、地空、地劫、红鸾、天喜、天姚、天刑必须说明其对主星的增强、限制、延迟或转向作用。

## 写作限制

禁止：某星代表 A，所以一定发生 B。

必须写成：该组合更容易形成 A 类行为机制；在 B 条件成立时，现实中可能表现为 C；若 B 不成立，则保留 D 解释。单星只提供线索，组合和运限才决定判断权重。

| 武曲 | 执行、数字、结果 | 与天府看管理；与七杀看硬任务；与贪狼看资源与欲望 | 煞忌多时关注僵硬、压力和财务风险 |

| 七杀 | 决断、竞争、突破 | 与紫微看权责；与武曲看执行；与破军贪狼看变化链 | 煞忌多时关注高压、冒进和恢复不足 |
| 破军 | 重建、切换、试错 | 与廉贞看规则破旧立新；与七杀看竞争变化；与紫微看平台重构 | 煞忌多时关注损耗、冲动和退路不足 |

## 联动判断最小模板

1. 先写主星各自功能，不先判吉凶；
2. 再写同宫后形成的新机制；
3. 用三方四正判断资源是否支持；
4. 用对宫判断外部牵引；
5. 用辅煞和四化判断增强、阻滞、转向或代价；
6. 用大限和流年判断何时更容易被看见；
7. 最后转换成两个以内的现实验证点。
