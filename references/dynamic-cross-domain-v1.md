# 动态运势与跨领域联动模块

## 适用范围

当用户询问大限、流年、流月、贵人、合作、团队、迁移、异地机会，或要求比较“事业与感情/财富/迁移”等多个主题的相互影响时，加载本模块。

本模块负责把静态命盘转换为“时间背景 + 触发领域 + 现实条件 + 联动结果”。它不替代基础盘面分析，也不把趋势写成必然事件。

## 一、先确定动态分析配置

```text
时间层级：本命 / 当前大限 / 指定流年 / 指定流月
主领域：事业 / 感情 / 财富 / 人际 / 迁移 / 健康 / 家庭
联动领域：最多选择两个最相关领域
现实场景：工作、关系、收入、居住、团队或其他
用户目标：判断机会、识别风险、选择方案或安排时间
数据状态：已排盘 / 已有运限 / 未扩展流年 / 未扩展流月
```

若用户只说“看最近运势”，默认分析当前大限、当前年份及未来三个月；若当前日期或流年资料不可用，明确标注缺失，不补造月份事件。

## 二、动态证据链与强度

每个动态判断都按以下顺序登记：

```text
静态基础 → 大限主题 → 流年触发 → 流月细化 → 现实条件 → 事件表现 → 反向表现
```

| 层级 | 主要回答 | 不可越界的结论 |
|---|---|---|
| 本命 | 哪些领域长期容易发生同类议题 | 不直接推出某年必然发生 |
| 大限 | 十年阶段把资源和压力集中到哪里 | 不等于十年内持续同一事件 |
| 流年 | 哪个领域被年度环境激活 | 不等于事件已经发生 |
| 流月 | 哪些月份更适合观察、推进或复盘 | 没有可靠月度数据时不得硬排月份 |

事件活跃等级使用四级制：0｜背景；1｜可观察；2｜明显；3｜高活跃。等级描述“议题活跃度”，不是事件好坏，也不是发生概率。机会与风险必须分别登记，不能用“高活跃”代替吉凶结论。

## 三、六个动态模块

### Module 1：人际 / 外部环境

区分贵人、合作方、团队成员、社交圈和竞争/消耗型关系，不把所有帮助者都称为贵人。贵人要说明对方通过资源、信息、背书、技能或关键介绍提供帮助；合作要检查目标、权责、交付、利益分配和退出机制；团队要观察角色变化、领导关系、协作效率和责任归属；人际风险重点写边界模糊、承诺过度、口舌误解、利益不对称和隐性竞争。输出至少包含有利对象/场景、风险对象/场景、可验证信号和边界动作。

### Module 2：迁移 / 环境变化

迁移不仅指搬家，也包括出差、异地工作、海外、跨平台、跨行业、进入新组织或接触新圈层。分别判断异地/海外的机会来源、信息差、适应成本和制度风险；换城市/换环境的生活成本、支持系统、工作方式和关系重组；外部机会究竟由地点变化、陌生人脉、组织转换还是市场变化带来。不能只写“适合外出”，必须给出触发条件、成本、适合的迁移尺度，以及先试运行还是直接切换。

### Module 3：大限

大限输出四项：十年核心主题；与上一限相比的人生阶段转换；适合积累、扩张或建立长期结构的强势领域；需要降杠杆、设边界或留出缓冲的弱势领域。大限只提供阶段背景，具体事件必须等待流年/流月触发并结合现实条件。

### Module 4：流年

流年输出年度主题、事件活跃等级、机会窗口和风险窗口。每个窗口必须写清：窗口对象 → 触发因素 → 可能表现 → 需要的现实条件 → 建议动作 → 失效信号。机会窗口关注启动、谈判、曝光、合作、迁移、收入结构变化；风险窗口关注冲突、过度承诺、合同、现金流、关系失衡和疲劳累积。窗口是适合观察或行动的阶段，不是保证结果的日期。

### Module 5：流月

流月只在有可靠月度资料或用户提供明确时间范围时使用。输出月度触发、事件强化和时间细化：是推进、暴露、重复、收尾还是复盘；时间表达优先使用月初/中旬/下旬或相对时间，只有资料足够时才给具体日期。不能凭单一星曜制造具体事件；没有月度依据时改写为“流年内需持续观察”，并给出观察指标。

### Module 6：跨领域联动

先确定主领域，再只展开最有依据的联动，不默认把六组全部写完。联动不是把两个专项报告拼接，而是回答“一个领域的变化如何改变另一个领域”。

| 联动 | 必须检查的传导关系 |
|---|---|
| 事业 × 感情 | 时间、承诺、情绪、异地、权力关系和共同规划 |
| 事业 × 财富 | 收入来源、现金流、风险承担、合同和投入回报 |
| 事业 × 迁移 | 地点变化、组织机会、适应成本、身份与资源网络 |
| 感情 × 迁移 | 距离、共同居住、家庭意见、关系承诺和迁移选择 |
| 感情 × 财富 | 共同支出、财务边界、价值观和依赖/控制风险 |
| 人际 × 事业 | 贵人/合作、团队角色、声誉、利益冲突和信息流 |

每组联动输出四层：主因 → 传导路径 → 现实表现 → 决策分流。决策分流至少覆盖“推进、试行、延后/复盘”三种路径，并说明每条路径的成立条件；不替用户做最终选择。

```text
动态结论编号：D-唯一编号

活跃等级：0/1/2/3
机会窗口：
风险窗口：
盘面依据：宫位、星曜、四化、运限或结构化数据
传导路径：从哪个领域影响哪个领域
主要表现：
反向表现：

验证信号：

```

同一动态结论只完整解释一次。其他领域引用编号，并只写该领域的具体表现。

## 五、用户可见输出模板

动态报告按以下顺序输出：一句话结论；时间总览；机会窗口；风险窗口；跨领域联动；现实分流；不确定性。正文优先使用现实语言：人物角色、合同、时间、地点、收入、责任、沟通、睡眠和生活安排。命理依据放在段末或附录，不让术语替代现实判断。

## 六、禁止的错误写法

- 把“贵人”写成必然出现的特定人物；
- 把“适合迁移”写成必须辞职、搬家或出国；
- 把活跃等级写成成功概率或吉凶等级；
- 用流月推断具体事故、疾病、分手或发财结果；
- 只罗列两个领域的结论，不解释传导路径；
- 在流年/流月数据缺失时补写具体年份、月份或日期；
- 把关系、健康、投资和职业建议写成替代现实决策的命令。
