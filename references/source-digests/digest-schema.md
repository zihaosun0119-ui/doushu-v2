# 来源摘录统一格式

每条资料只记录实际读取到的内容，不根据标题补全正文，不把搜索摘要当作全文。

## 来源记录

- `source_id`：稳定编号。
- `title`：页面或出版物原题。
- `author_or_publisher`：页面明确提供时填写；无法确认写“未核实”。
- `source_type`：古籍原文／现代专著／论文或机构资料／课程目录／社交媒体讲解／案例。
- `url_or_local_path`：精确到实际读取页面或文件。
- `accessed_at`：访问日期。
- `access_level`：全文／章节／目录／摘要／搜索片段／无法访问。
- `downloaded_copy`：本地保存路径；未下载写“无”。
- `reliability_tier`：A／B／C／D。
- `independence_group`：同源转载、同一作者或同一案例使用相同组名，避免伪造多源印证。

## 内容摘录

- `explicit_claims`：来源明确陈述的规则或判断。
- `scope`：适用对象、宫位、星系、运限或案例条件。
- `method`：来源实际采用的判断顺序和组合方式。
- `case_facts`：案例已公开的出生资料、盘面事实、现实反馈；缺失项必须标注。
- `usable_inferences`：只能写由原文直接支持或经过至少两个独立来源交叉支持的推论。
- `unsupported_or_unclear`：资料未说明、版本存在差异或尚不能确认之处。
- `duplicate_links`：重复转载或同源页面。

## 可靠性分级

- A：可核对的古籍原文、学术论文、正式出版物全文或清晰页码扫描。
- B：正式出版物可核对章节、作者公开课程原文、信息完整且有反馈的案例。
- C：平台讲解、个人文章、目录或摘要；可用于发现线索，关键规则须交叉核验。
- D：无作者、无原文、出生信息或反馈残缺、明显转载但找不到首发；不得单独支撑结论。

## 强制规则

1. 搜索结果页只用于定位，不能充当最终证据。
2. 付费、登录或版权限制内容不得绕过限制抓取；只记录公开可见部分。
3. 案例事实与作者解释分栏记录，不能把解释写成已发生事实。
4. 两个网址若源于同一书、同一视频或同一案例，只算一个独立来源。
5. 每项进入格局卡前，必须能回指 `source_id` 和具体摘录位置。
