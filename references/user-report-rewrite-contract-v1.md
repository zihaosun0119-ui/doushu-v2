# 用户报告改写契约

## 目标

基于已完成的分析稿，输出一份独立的用户报告。用户报告直接呈现盘面出处、合理推论、现实表现、时间窗口和行动建议。

## 强制要求

1. 完整保留分析稿中除推论过程以外的全部讨论，不得把完整报告压缩成短摘要。
2. 感情专项可以保留夫妻宫、迁移宫、交友宫、田宅等出处，并把术语翻译成脸型、家庭资源、场合和行为。
3. 时间表按固定流月数据列出农历月份、相遇场合、触发事件和关系落点；不得用一行年度标签代替。
4. 感情专项必须包含外貌、家庭财富层次、性格、相处模式、相识方向/场合/事件和给用户的进入建议。
5. 健康内容只能写作息、压力、恢复、检查和就医建议，不作诊断；财务内容不作收益保证。
6. 感情报告不生成 Must-have、Dealbreaker、现在怎么做、资料边界独立章节；建议直接放进相识路径与时间点表。
7. 使用简体中文，结论在前，专业、直接、具体；避免空话、重复和安慰性套话。
8. PDF 首屏必须先呈现总判断、3—5 条重点和当前阶段重点。用户要求逐月时，增加完整的月度总览；每月必须有主题、场合、触发事件、关系落点和建议。

## 验收

- 用户报告可独立阅读，不需要了解命理术语。
- 与完整分析稿相比，讨论范围不缩水，只删除过程性术语和依据。
- 读者能知道每个阶段应观察什么、规避什么，以及当前可执行的动作。
