# 用户报告改写契约

## 目标

基于已完成的完整分析稿，输出一份独立的用户报告。分析稿保留全部盘面依据、推理链和不确定性；用户报告只呈现已经成立的现实结论、可能表现、判断条件、时间窗口、风险和行动建议。

## 强制要求

1. 完整保留分析稿中除推论过程以外的全部讨论，不得把完整报告压缩成短摘要。
2. 用户报告不得出现或解释盘面术语，包括但不限于：星曜、宫位、四化、三方四正、庙旺、命盘、流年落宫、大限、飞星、格局、干支，以及“根据某星/某宫”的表达。
3. 可以保留年份、阶段、风险等级和置信度；年份只能作为观察窗口，不写成必然事件。
4. 必须按任务范围保留并现实化改写长期发展模式、事业与工作方向、财务、关系与合作、健康与恢复、迁移/家庭/社会关系、阶段节奏、主要路径、分阶段行动方案、验证点与边界。
5. 每个结论写明适用条件或替代解释。健康内容只能写作息、压力、恢复、检查和就医建议，不作诊断；财务内容不作收益保证；关系和事业不作确定性预测。
6. 用户报告按“资料说明 → 先说结论 → 可能表现 → 如何判断 → 各领域讨论 → 时间节奏 → 主要路径 → 现在怎么做 → 验证与边界”组织；仅在用户明确要求时调整结构。
7. 使用简体中文，结论在前，专业、直接、具体；避免空话、重复和安慰性套话。

## 验收

- 用户报告可独立阅读，不需要了解命理术语。
- 与完整分析稿相比，讨论范围不缩水，只删除过程性术语和依据。
- 读者能知道每个阶段应观察什么、规避什么，以及当前可执行的动作。
