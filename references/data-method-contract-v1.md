# 固定数据口径

每次报告只使用这一套数据链；缺项时重新排盘，不拼接不同来源的结果。

| 数据 | 固定来源与方法 | 必须保存 |
|---|---|---|
| 紫微命盘 | 本地 `iztro@2.6.0`，按确认后的公历/农历、性别、时辰、闰月与真太阳时排盘 | 十二宫、命身、大限、四化、算法版本 |
| 八字 | 同一次 `iztro` 排盘的 `rawDates.chineseDate` | 年、月、日、时四柱，不只存一行文本 |
| 流年 | 同一命盘的 `horoscope(目标年)` | 流年宫位、天干地支、四化 |
| 流月 | 同一命盘的 `monthlyList(目标年, true)` | 每个农历月的宫位、月干支、四化；闰月前后半月分别记录 |

## 固定规则

- 流月宫位：采用 `iztro` 的斗君算法。
- 月干与四化：采用 `iztro` 的五虎遁结果。
- 交界：按农历月和闰月分段，不按公历每月 15 日抽样。
- 八字、紫微、流年、流月必须来自同一份出生资料和同一算法版本。

## 缺项处理

1. 缺出生日期、时刻、性别、历法或闰月：停止并询问。
2. 缺出生地、时区或真太阳时判断：记录缺口；可能跨时辰时停止单盘判断。
3. 缺八字四柱：重新运行同一次 `iztro` 排盘。
4. 缺流年：重新生成目标年份的 `horoscope`。
5. 缺流月宫位、月干支或四化：重新生成 `monthlyList`；仍不完整则不输出月份。

## 链接记录

在数据清单和 `execution-manifest.json` 记录：输入文件、命盘文件、流年/流月文件、算法版本、生成时间和 SHA-256。任何一个来源或版本变化，都重新生成受影响的数据。
