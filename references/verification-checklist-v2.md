- [ ] 出生日期、时间、性别、出生地、历法和时区已核验或标缺。
- [ ] 真太阳时跨时辰风险已判断；无风险时未强制校正，有风险时已校正或双盘比较。
- [ ] 结构化命盘来自可靠算法或用户提供资料，不含凭记忆补盘。
- [ ] 十二宫、命身、五行局、主辅煞曜、庙旺平陷、生年四化和大限可追溯。
- [ ] 完整报告已读取 `brightness-source-v2.md`，并运行 `enrich-brightness.js` 或核验已有同口径亮度字段。

## B. 流年数据

- [ ] 排盘后已运行流年扩展脚本。
- [ ] 流年文件存在，目标年份、流年命宫、年干四化可读。
- [ ] 默认覆盖当前大限；无法换算时至少覆盖当前年前两年至后五年。

## C. 推断质量

- [ ] 报告开头分列“依据、根据、验证状态”，未把资料、意象和结论混写。
- [ ] 命宫与身宫先于其他领域分析。
- [ ] 命宫三方四正已解释事件链，不只列宫位。
- [ ] 日月关系和格局集中归类，包含构成、支持、反证和流派差异。
- [ ] 每个重要判断至少引用三类依据。
- [ ] 已区分性格倾向、生活主题、事件场景和时间窗口。
- [ ] 报告全局明确分为“专业推论”和“现实转换”两个区块。
- [ ] 专业推论区只写盘面判断、组合推理、成立条件和置信度，没有把推测写成已发生事件。
- [ ] 现实转换区使用普通读者能理解的对象、场景、触发条件和动作，没有重新堆叠星曜释义。
- [ ] 同一自然段没有混合星曜推论与具体现实事件。
- [ ] 专业术语后紧跟现实后果；加粗重点落在后果、风险或行动，不只加粗星曜名称。
- [ ] 缺口未被用作终止分析的理由；仍有主判断、替代解释、成立条件、验证和建议。
- [ ] 多流派内容标明来源、共识、差异和争议，没有混成唯一标准。
- [ ] 需要多流派或存在关键歧义时已读取 `nihaixia.md`；未采用时已在资源调用记录说明原因。

- [ ] 工作分析覆盖命宫、官禄、财帛、迁移、福德、交友及运限。

- [ ] 职场风险只检查当前案例有依据的部分，并包含相应的依据、现实表现和验证或行动建议。
- [ ] 财务、关系、健康、迁移和家庭均有条件化结论与可执行建议。
- [ ] 健康条件化推测（`health-conditional-inference-v1`）包含专业依据、主要可能表现、替代解释、成立条件、现实验证和行动建议，没有因缺少体检反馈而只写“不能判断”。
- [ ] 健康内容结构清晰，专业推论列出实际采用的盘面依据；标题可随案例调整。
- [ ] 健康内容没有把命盘推测写成疾病诊断；疾病事实仅来自用户反馈或可靠医疗资料。
