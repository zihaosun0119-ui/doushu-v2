# 03 完整命局报告模块

## 输入

`01-input-intake`、`02-chart-data`、`03-analysis` 均为 `passed`，且任务中 `report_mode = complete` 或 `reportTypes` 包含 `full`。

## 动作

读取 `references/complete-report-mode-v1.md`，把已经完成的飞星基础层提升为独立飞星因果链，同时保留河洛独立链；两条链分别记录源宫、落宫、层级、现实含义和资料缺口，再进入多派对照。

完整模式必须覆盖本命全盘、命身、命疾福、命财官迁、财福、夫妻官禄、交友兄弟、父母田宅子女等有依据的结构。不得平均铺写十二宫；同一条禄忌链只完整解释一次，其他专题引用其现实表现。

关键三方四正只在实际承接时调用，但完整模式至少核验命财官迁、夫妻官禄、财福和交友官禄；输出本宫、三方、对宫、四化/星曜承接和现实分流。

如果用户同时提出跳槽/创业、留下/离开等选择，追加决策支持；如果已有大限、流年、流月范围，追加动态跨领域。流日流时仍须用户明确要求。

模块完成后登记 `complete_scope`、`feixing_full_chain`、`helu_full_chain`、`trine_review`、`decision_support`、`cross_domain` 和结论覆盖摘要，交给 `04-quality-delivery`。

## 输出

完整命局分析稿、飞星独立链、河洛独立链、关键三方四正核验、全盘现实专题、运限时间层、多派对照、决策支持结果、资料缺口、结论编号和完整模式 Preflight 记录。

## 门禁

任一独立方法链缺失、三方四正被完全省略、全盘范围没有覆盖、跨领域结论无传导路径、选择题没有条件分流、缺少现实验证点或把缺失资料写成确定结论：`failed`。修复前不得进入正式用户报告。
