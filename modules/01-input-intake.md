# 01 输入询问模块

## 输入

用户文字、结构化命盘或已有输入状态。

## 动作

先读取并执行 `references/report-selection-gate-v1.md`，确认用户选择的 `reportTypes`；再读取 `references/input-intake-gate-v2.md`，核对历法、出生日期、出生时间及准确程度、性别、出生地、时区、真太阳时风险、报告方向和分析时间范围。用户说“完整命局、全盘分析、完整分析报告、全盘详细分析”等时，除记录 `reportTypes = ["full"]` 外，设置 `report_mode = complete`；若用户明确要求飞星/四化模式，追加确认 `method_profile = feixing`、四化表版本和流月采用的斗君/五虎遁规则；若未明确指定，四化表按对应模式默认值并在报告开头声明。

只集中询问阻塞任务的缺项。出生时间不明确或可能跨时辰时，先确定范围；用户明确要求比较且其他排盘必需资料齐全后，以候选比较模式进入数据模块，分别排盘后再比较。不得在排盘前臆造候选盘的行为差异，也不得把经历吻合记为出生事实。

## 输出

完整的 `report_selection` 与 `input_intake` 状态、待询问项、时间确认方式和任务配置。

## 门禁

报告选择未确认、任一排盘必需项缺失，或时间范围不明且未能建立获准的候选比较：`pending`，停止后续模块。候选比较授权通过的是比较任务的输入门禁，不代表某个出生时刻已确认。
